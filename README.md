# 학교 PC 자가점검

교직원이 스스로 자기 PC의 상태를 확인하고, **조치까지 따라 할 수 있게** 만든 단일 HTML 페이지입니다.
설치할 것도 서버도 없습니다. 파일 하나를 열면 끝입니다.

> 나이스·업무포털용 보안 프로그램이 깔린 학교 PC를 전제로 만들었습니다.
> 끄면 안 되는 프로그램 목록이 조치 절차 안에 함께 표시됩니다.

---

## 무엇을 하나

| 탭 | 하는 일 |
|---|---|
| **점검하기** | 점검 스크립트 실행 → 결과 붙여넣기 → 신호등 판정과 '지금 할 일' |
| **조치 방법** | 문제별 단계별 해결 절차. 난이도(초급·중급·고급)로 나뉨 |
| **관리 루틴** | 매주·매월·분기 체크리스트. 주기가 바뀌면 자동 초기화 |
| **정보부** | 여러 교직원의 결과 파일을 모아 비교. 공통 문제 자동 탐지 |
| **배포 안내** | 교직원께 보낼 안내문과 배포 방법 |

## 왜 스크립트와 웹앱이 나뉘어 있나

브라우저는 보안 샌드박스 안에 있어 **메모리·CPU·시작프로그램을 직접 읽을 수 없습니다.**
"버튼 하나로 내 PC 진단"은 웹앱만으로는 원리적으로 불가능합니다.

그래서 역할을 나눴습니다.

```
PowerShell 스크립트  →  JSON을 만들어 클립보드에 복사   (센서)
                     ↓
          사용자가 웹앱에 Ctrl+V
                     ↓
   웹앱이 판정 · 기록 · 추세 · 조치 안내              (계기판)
```

점검 스크립트는 **읽기 전용**입니다. 설정을 바꾸거나 파일을 지우지 않고, 관리자 권한도 필요 없습니다.

## 쓰는 법

1. 페이지를 엽니다
2. **스크립트 복사** → 메모장에 붙여넣기 → `PC점검.ps1` 로 저장
   - 파일 형식: **모든 파일**, 인코딩: **UTF-8(BOM)**
   - 이 두 가지에서 대부분 막힙니다. `.txt` 로 저장되면 실행되지 않고, BOM이 없으면 한글이 깨집니다.
3. 저장한 파일 **우클릭 → PowerShell로 실행**
4. 끝나면 **브라우저가 저절로 열리고 결과가 바로 나옵니다.** 붙여넣을 것이 없습니다.

### 결과가 돌아오는 길

복사되는 스크립트에는 이 페이지의 주소가 이미 적혀 있습니다. 페이지가 `location` 으로
자기 주소를 읽어 넣기 때문에, 어디에 올리든 손으로 고칠 일이 없습니다.

```
점검 끝 → 결과를 base64 로 바꿔 주소 뒤에 붙임
        → Start-Process 로 그 주소를 엶
        → 페이지가 #d= 를 읽어 바로 판정
```

`#` 뒤의 값은 **서버로 전송되지 않습니다.** 브라우저 안에만 머물기 때문에
측정값이 PC 밖으로 나가지 않습니다. 결과가 주소 한계를 넘길 만큼 길면 스크립트가
클립보드 방식으로 물러서고, 페이지를 열어 붙여넣도록 안내합니다.

붙여넣기로 쓰실 때도 **붙여넣는 순간 바로 분석**됩니다. 버튼을 누르지 않아도 됩니다.

실행 정책 오류가 나면 PowerShell에서 한 번만:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

## 난이도 기준

*아는 것이 많은지*가 아니라 **실수했을 때 되돌릴 수 있는지**로 나눴습니다.

| 난이도 | 기준 | 해당 조치 |
|---|---|---|
| **초급** | 지우는 것이 없고 설정도 되돌아감 | 재부팅 · OneDrive 공간 확보 · 스크립트 오류창 끄기 |
| **중급** | 끄거나 닫는 동작. 같은 자리에서 복구 가능 | 자동 시작 끄기 · 메모리 확보 |
| **고급** | 삭제가 포함되거나 중간에 멈추면 안 됨 | 디스크 공간 확보 · 죽은 시작 항목 제거 · 시스템 파일 복구 |

조치 방법 탭에서 **난이도 필터**로 한 수준만 볼 수 있습니다.
초급 항목만 해도 대부분 좋아집니다.

## 우리 학교에 맞게 고치기

`index.html` 하나만 고치면 됩니다. 설정값은 한곳에 모아두었습니다.

### 판정 기준

```js
const RULES = {
  mem:  { warn:70, bad:85 },                    // 메모리 사용률 %
  disk: { warn:20, bad:10, lowerIsWorse:true }, // 디스크 여유 %
  cpu:  { warn:1,  bad:3 }                      // 최상위 프로세스 분당초
};
```

사양이 낮은 PC가 많으면 메모리 기준을 `{ warn:80, bad:92 }` 처럼 올리세요.

### 끄면 안 되는 프로그램

```js
const KEEP = [
  ["AhnLab Safe Transaction", "업무포털 구간 암호화"],
  // 우리 학교에 설치된 보안 프로그램을 여기에 추가
];
```

이 목록은 **관리 루틴 탭의 표**와 **자동 시작 끄기 절차 안의 경고**에 동시에 쓰입니다. 한 번만 고치면 됩니다.

### 조치 난이도

```js
const FIX_TIER = {
  reboot:1, onedrive:1, scripterr:1,
  startup:2, memory:2,
  disk:3, deadlink:3, sysfile:3
};
```

### 관리 루틴 항목

`const TASKS` 의 배열에 `["항목 이름", "설명", 난이도]` 를 추가하면 체크리스트에 바로 나타납니다.

## 개인정보

- 점검 결과는 **그 PC의 브라우저에만** 저장됩니다 (`localStorage`). 서버로 전송되지 않습니다.
- 결과에는 프로그램 이름과 사용량만 담기고, 파일명이나 문서 내용은 들어가지 않습니다.
- 다만 **설치된 프로그램 목록은 개인 사용 습관을 드러낼 수 있습니다.**
  결과 회수는 강제하지 말고 희망자만 받으시길 권합니다.

## 배포

`index.html` 하나뿐이라 어디에 올려도 됩니다.

**GitHub Pages** — Settings → Pages → Source를 `main` / `/ (root)` 로 지정하면
`https://<사용자명>.github.io/<저장소명>/` 으로 열립니다.

**교내 공유폴더** — 파일을 복사해 두고 더블클릭해도 똑같이 작동합니다. 인터넷 없이도 됩니다.

## 만들며 겪은 것

이 저장소가 다른 분께 쓸모 있다면 코드보다 이 부분일 수 있어 적어둡니다.

- **조용한 실패가 가장 위험하다** — 첫 배포본은 내보내기 버튼이 아무 일도 하지 않았습니다.
  호스팅 환경이 일반 다운로드를 막는데 코드는 오류 없이 통과했기 때문입니다.
  지금은 기능을 쓸 수 있는지 먼저 확인하고 세 단계로 물러섭니다.
- **시간은 지우지 말고 서랍을 바꾼다** — 체크리스트 초기화를 타이머로 풀면 복잡해집니다.
  저장 키에 기간을 넣으면(`weekly:2026-11-10`) 주가 바뀔 때 저절로 빈 상태가 됩니다.
- **권한을 적게 쓸수록 배포가 쉽다** — 여러 PC 취합에 DB를 두면 보안 검토 대상이 됩니다.
  각자 파일로 내보내고 한 사람이 불러와 합치면 권한이 하나도 필요 없습니다.
- **경고는 쓰는 화면에 둔다** — 끄면 안 되는 목록을 다른 탭에 두었더니 아무도 보지 않았습니다.
  끄려는 절차 안으로 옮겼습니다.
- **주소를 적어 넣게 하지 않는다** — 안내문의 링크도, 스크립트가 돌아올 주소도
  페이지가 `location` 으로 스스로 채웁니다. 사람이 손으로 옮겨 적는 자리는
  언젠가 반드시 틀립니다.
- **손이 가는 단계가 이탈 지점이다** — 가장 많이 멈추는 곳은 어려운 단계가 아니라
  창을 옮겨 붙여넣는 단계였습니다. 그 한 단계를 없앴습니다.
